=== Lei Notes ===
Version: 1.0.0
Requires at least: 6.7
Requires PHP: 8.0
License: GPL-2.0-or-later

面向开发者写作的 WordPress 区块主题。正文、文章列表和分类由 WordPress 在服务器输出。

== 安装与删除 ==
后台 → 外观 → 主题 → 添加主题 → 上传主题，选择 lei-notes-1.0.0.zip，安装后启用。
也可以把完整 lei-notes 文件夹放进 wp-content/themes。
启用主题不会导入示例、创建页面、用户、数据表或计划任务，也不会修改固定链接设置。
更换主题：先启用其他主题。删除：在外观 → 主题打开 Lei Notes 的主题详情并删除。
文章、分类、标签、媒体、评论均为 WordPress 标准内容，停用和删除主题不会清除它们。
WordPress 通常保留该主题的设置、模板覆盖和全局样式；删除主题文件不等于清空数据库。
如需重新使用默认版面，在站点编辑器中重置相应模板。升级前请备份自定义内容。

== 后台编辑入口 ==
外观 → 编辑器：
• 模板：博客首页、文章详情、归档、搜索、普通页面、404，以及可选的侧栏文章和无标题页面。
• 模板部件：页头、页脚、文章侧栏。导航使用原生导航区块，可增删链接。
• 样式：字体、配色、内容宽度、宽幅宽度、区块间距等。默认正文宽 850px、宽幅 1040px。
• 首页介绍、文章列表、页脚居中文字均可直接编辑；区块没有锁定，可移动、删除或替换。
• 文章列表使用原生查询循环。默认继承主查询，每页数量在设置 → 阅读中控制；关闭继承后可按查询区块条件配置。

外观 → Lei 主题设置：
默认外观（系统/白天/黑夜）、字标动画、固定页头、朗读、代码高亮复制、代码行号、图片放大、回顶按钮、基础 SEO 以及社交链接。
访客的外观选择只保存在自己的浏览器中，并优先于后台默认值。
社交链接默认留空，前台显示不可点击的图标占位；填入完整 HTTP(S) 网址后成为链接。

== 主题功能区块 ==
Lei 标识：手写签名、站点文字或上传的站点 Logo，可单独关闭动画。
外观切换：可移动、删除，支持修改入口文字。
文章信息：分类、日期、阅读时间、朗读按钮均可单独显示或隐藏。
文章目录：从文章的二三级标题生成；支持原生标题锚点；不足两项时隐藏。
页脚链接：社交网址可覆盖全局设置，RSS、文章地图、XML 地图分别开关。
版权：自动年份，可自定义名称；留空使用站点名称。
文章分类：列出已有文章的分类，使用真实归档链接。
文章地图：公开文章分页索引，可选包括页面。
这些功能区块一般放在模板中；文章正文建议使用原生区块，切换其他主题仍可完整显示内容。

== 写文章与图片 ==
在文章编辑器使用原生段落、标题、引用、列表、图片、画廊等区块。
特色图片用于首页缩略图及详情页头图；正文图片支持点击放大，已包含链接的图片保留原链接行为。
代码使用原生“代码”区块。在右侧“代码展示”面板选择语言，可填写文件名。
支持 JavaScript、TypeScript、YAML、Bash、JSON、Python、PHP、HTML、CSS、Go、SQL 及纯文本。
高亮脚本随主题本地提供，无需 CDN。行号属于独立界面，不写入正文，也不参与复制。
关闭主题增强或更换主题后，代码仍是普通可读代码块。

== 朗读与动画 ==
朗读使用设备语音，不调用付费音频 API；音色质量和可用语言取决于浏览器与系统。
支持段落高亮、语速/音色选择、暂停继续停止、平滑跟随和手动滚动后的临时让位。
精确到字词的高亮取决于浏览器语音边界和 Highlight API 支持；不支持时按段落高亮。
签名字标按 L、E、I 依次书写并循环，默认持续播放；可从区块或全局主题设置关闭。

== 搜索、订阅与抓取 ==
文章、分类、标签、搜索都使用 WordPress 原生固定地址。更换域名时无需重新编译主题。
页脚“文章地图”是动态公开文章索引；“XML”指向 WordPress 原生站点地图，RSS 为原生订阅。
主题尊重设置 → 阅读中的搜索引擎可见性；关闭索引时不显示 XML 入口。
基础 SEO 提供描述、规范地址、Open Graph 与 BlogPosting JSON-LD。
检测到 Yoast、Rank Math、AIOSEO 或 SEOPress 时让这些插件接管相关页面信息，避免重复输出。
公开网站仍需正确域名、HTTPS、服务器访问权限及抓取策略；主题不承诺搜索或 AI 一定收录。
本地 localhost 页面无法被公网爬虫访问。

== 示例内容 ==
示例导入工具仅放在项目 tools 中，不包含在主题安装包，也不会随启用运行。
导入五篇技术文章、两张 CC0 摄影和一张原创示意图，保留站点已有文章与页面。
正文均保存为原生区块，可在后台继续编辑。重复运行导入器会跳过带相同标记的文章，不覆盖改动。
文章标记：_lei_notes_demo_slug / _lei_notes_demo；媒体标记：_lei_notes_demo_asset。
可在后台把不需要的示例文章移入回收站；图片独立保存在媒体库，确认无其他文章引用后再自行清理。
